# Qunsheng Zhang · Academic Homepage

张群声的学术个人主页，聚焦 AI Agent、可信人工智能、多智能体系统与强化学习研究。

## 访问

- GitHub Pages: <https://usst-zqs.github.io/>

## 本地预览

网站是静态页面，在当前目录启动任意静态文件服务器即可，例如：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 内容结构

- `index.html`：个人简介、教育经历、荣誉、工作经历、新闻和代表论文
- `publications.html`：论文列表
- `projects.html`：项目与研究经历
- `showcase.html`：研究方向与技术能力
- `blog.html`：文章与研究笔记入口
- `styles.css`：全站样式与响应式布局
- `assets/`：头像、经历徽标、论文封面和可下载简历

推送到 `main` 分支后，由 GitHub Pages 自动发布。
