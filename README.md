# Qunsheng Zhang · Personal Website

张群声的个人主页，聚焦 AI Agent、可信人工智能、多智能体系统与强化学习研究。

## 访问

- GitHub Pages: <https://usst-zqs.github.io/>

## 本地预览

网站是零依赖静态页面，在当前目录启动任意静态文件服务器即可，例如：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 内容结构

- `index.html`：主页内容与语义结构
- `styles.css`：视觉系统、响应式布局与动效
- `script.js`：多智能体首屏动画、导航与滚动交互
- `assets/`：头像、图标和可下载简历

推送到 `main` 分支后，由 GitHub Pages 自动发布。
